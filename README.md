One word an agent says when it has no idea what to do: **null**.

An agent caught out mid-task blurts the only thing it actually has — its own
empty state. No caption needed, no second read: asked "what do I do?", the
agent answers with literal nothingness.

`main.ts` writes exactly those four bytes to `/output/entry.txt`.
